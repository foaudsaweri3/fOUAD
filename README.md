# Лабораторная работа №1: Динамическое программирование
Теоретическая часть
1. Динамическое программирование
Динамическое программирование — это метод решения сложных задач путем разбиения их на более простые подзадачи. Основные характеристики:

Оптимальная подструктура: оптимальное решение задачи может быть составлено из оптимальных решений подзадач

Перекрывающиеся подзадачи: одни и те же подзадачи решаются многократно

Основные подходы:

Нисходящее программирование (Top-Down): рекурсия с мемоизацией

Восходящее программирование (Bottom-Up): итеративное заполнение таблицы

Области применения:

Оптимизационные задачи

Задачи на графы и пути

Распределение ресурсов

Биоинформатика и выравнивание последовательностей

2. Big O нотация
Big O нотация — это математическая нотация для описания асимптотического поведения функций при стремлении аргумента к бесконечности.

Основные классы сложности:

O(1) — константная сложность

O(log n) — логарифмическая сложность

O(n) — линейная сложность

O(n log n) — линейно-логарифмическая сложность

O(n²) — квадратичная сложность

O(2ⁿ) — экспоненциальная сложность

В контексте решенных задач:

Climbing Stairs: O(n) время, O(1) память

Jump Game II: O(n) время, O(1) память

Pascal's Triangle: O(n²) время, O(n) память

Best Time Stock I/II: O(n) время, O(1) память
